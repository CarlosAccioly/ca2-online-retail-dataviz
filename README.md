# CA2 – Online Retail Data Visualisation

**Module:** Data Visualisation and Communication – CCT College Dublin
**Student:** Carlos Eduardo Sabino Accioly Silva (2023319)

## About
Analysis of an online gift wholesaler's transactions (Dec 2010 – Dec 2011):
data quality assessment, cleaning, exploratory data analysis and an
interactive dashboard for managers.

## How to run
1. Install the libraries: `pip install -r requirements.txt`
2. Download `Online_Retail.xlsx` from Moodle and place it in a `data/` folder
   (the data is not included in this repository).
3. Open `CA2_DataVis_2023319.ipynb` in Jupyter and run all cells.

## Files
- `CA2_DataVis_2023319.ipynb` – main notebook
- `requirements.txt` – Python libraries used
